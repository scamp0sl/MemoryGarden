---
description: How to safely restart the MemoryGardenAI server
---

To restart the MemoryGardenAI service, you must execute the provided `start_server.sh` script rather than running Python or Docker commands manually.

1. Navigate to the project root directory
2. Execute the start script
// turbo
```bash
cd /home/admin/docker/MemoryGardenAI && ./start_server.sh
```
