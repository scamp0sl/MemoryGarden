핵심 차별점

기존 솔루션 vs 기억의 정원

구분 🆚 기존 접근법 기억의 정원
접근성 → 병원 방문 필수 카카오톡에서 매일 2~3분
측정 방식 → 1회성 검사 (MMSE/MoCA) 30일+ 종단적 추적
사용자 경험 → "시험" 느낌 → 거부감 "정원 가꾸기" 놀이 → 습관화
판정 기준 → 절대 점수 기반 개인 내 변화(slope) 중심
분석 차원 → 단일 지표 6차원 복합 분석 (MCDI)
개입 시점 → 증상 발현 후 (사후 진단) 미세 변화 감지 + 조기 넛지
가족 참여 → 환자만의 문제 보호자 대시보드 + 의료 연계

6가지 대화 카테고리

각 영역별 특정 인지 기능 측정

🌸

A. 회상의 꽃밭 (Reminiscence Therapy)

측정 대상: 일화적 기억, 어휘 풍부도, 서사 구조화 능력

질문 예시:
"어릴 때 봄이 오면 꼭 하시던 일이 있으셨나요? 동네에서 놀거나, 소풍을 가거나..."
원격 기억 측정 감각적 디테일 시간 순서 구조
🍽️

B. 오늘의 한 접시 (Daily Episodic Encoding)

측정 대상: 단기 기억 인코딩 및 재인, 시각-언어 연계

작동 방식:
오전 11:30 → "점심 뭐 드실 예정이세요? 사진 찍어주세요!" 📸
오후 6:00 → "오늘 점심에 들어간 재료 3가지만 말씀해주세요!"
6시간 지연 회상 멀티모달 분석 자유회상 vs 재인
🌻

C. 이름 꽃밭 (Semantic Memory & Naming)

측정 대상: 이름대기, 범주 유창성, 의미 기억

질문 예시:
"30초 안에 '과일' 이름을 최대한 많이 말씀해주세요! 🍎🍊🍇"
범주 유창성 점수 군집화 패턴 전환 능력
🗓️

D. 시간의 나침반 (Temporal Orientation)

측정 대상: 시간적 지남력, 계절감, 시제 혼동

직접 측정: "오늘이 무슨 요일인지, 몇 월인지 말씀해주세요!"
간접 측정: "요즘 쌀쌀해졌죠? 이 계절에 드시고 싶은 음식이 뭐예요?"
⚠️ 7월에 "군고구마"라고 답하면 계절감 불일치 감지
🎨

E. 그림 읽기 놀이 (Visual-Linguistic Integration)

측정 대상: 시공간 인지, 주의력, 기술 능력

과제: 복잡한 일상 장면 이미지 제시 (쿠키 도둑 그림 변형)
"이 그림을 보고 무엇이 보이는지 자유롭게 설명해주세요~"
요소 언급 개수 행위 기술 공간 관계 표현
🧩

F. 선택의 정원 (Non-verbal Cognitive Screening)

측정 대상: 시각적 주의력, 패턴 인식, 실행 기능 (언어 부담 최소)

과제 예시:
"아래 4개 중 나머지 셋과 다른 하나를 골라주세요!"
🌷🌷🌷🌻 → 정답: 🌻
반응 시간 추적 정답률 트렌드 교육수준 무관

4단계 위험도 분류

Traffic Light 시스템

☀️
GREEN (정상 범위)

조건: MCDI ≥ 70 AND 최근 4주 기울기 > -0.5/주

메시지: "정원이 건강하게 자라고 있어요!"

조치: 일상 모니터링 지속

🌤️
YELLOW (관찰 필요)

조건: MCDI 50~70 OR 기울기 -0.5~-1.5/주

메시지: "정원에 구름이 조금 낀 것 같아요"

조치: 질문 빈도·난이도 조정, 교란변수 체크

🌧️
ORANGE (주의)

조건: MCDI 30~50 OR 기울기 < -1.5/주 OR 2개 이상 지표 2σ↓

메시지: "정원에 비가 내리고 있어요. 건강 점검 어떠세요?"

조치: 보호자 알림 + 병원 방문 넛지

⛈️
RED (즉시 조치)

조건: MCDI < 30 OR 지남력 반복 실패 OR 자기정보 오류

메시지: (보호자 중심 알림)

조치: 보호자 즉시 통보 + 의료기관 연계 권고 + 임상 리포트 제공

⚠️ 중요: 일시적 인지 저하 요인(수면 부족, 우울, 감기 등)을 스크리닝하여 False Positive를 최소화합니다. 교란 변수 확인 전까지 최대 3일간 알림을 보류합니다.

  • 시제 혼동: 5회 관찰

■ 임상적 해석 및 권고사항

종합 소견:

30일간의 일상 대화 분석에서, 다음 영역에서 baseline 대비 통계적으로 유의미한 저하가 관찰되었습니다:

  1. 어휘 인출 능력의 현저한 저하 (naming difficulty)
  2. 일화 기억의 인코딩 및 인출 장애
  3. 서사 구조화 능력의 저하
  4. 시간적 지남력의 부분적 장애
  5. 전기적 기억(자녀 이름, 고향)의 불일치

권고사항:

상기 소견은 경도인지장애(MCI) 또는 초기 알츠하이머형 치매의 가능성을 시사하며, 정밀 신경심리검사(SNSB-II 등) 및 뇌 영상 검사(MRI, PET)를 통한 확인 진단을 권고드립니다.
