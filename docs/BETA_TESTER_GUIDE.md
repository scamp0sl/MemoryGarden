## 1. 서비스 소개

**기억의 정원**은 매일 자연스러운 대화를 통해 인지 건강을 관리해 드리는 AI 서비스입니다.

```
┌─────────────────────────────────────────────────────┐
│                   기억의 정원 🌿                      │
│                                                       │
│  하루 3번 AI가 먼저 말을 걸어요                       │
│    ↓                                                  │
│  카카오 채널방에서 자연스럽게 대화해요                │
│    ↓                                                  │
│  AI가 대화 내용을 분석해서 인지 건강을 체크해요       │
│    ↓                                                  │
│  분석 결과는 DB에 누적 저장됩니다                     │
│  (보호자 알림은 정식 서비스 시 지원 예정)             │
└─────────────────────────────────────────────────────┘
```

### 대화 일정

| 시간 | 내용 |
|------|------|
| 오전 9:00 | 아침 인사 + 오늘의 질문 |
| 오후 2:00 | 오후 안부 + 기억 이야기 |
| 저녁 7:00 | 저녁 인사 + 하루 정리 |

## 2. 시작하기 (최초 설정)

> ⚠️ **중요**: 서비스를 제대로 이용하려면 **두 가지 설정**이 모두 필요합니다.
> 카카오 로그인(OAuth)과 채널 추가를 **둘 다** 완료해야 합니다.

### 전체 설정 흐름

```
[1단계] 카카오 로그인      [2단계] 채널 추가          [3단계] 연동 완료
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│                  │     │                  │     │                  │
│  서비스 URL 접속  │ ──▶ │  @기억의정원     │ ──▶ │  AI가 채널방에서  │
│  카카오 로그인   │     │  채널 추가하기   │     │  대화를 시작해요  │
│                  │     │                  │     │                  │
└──────────────────┘     └──────────────────┘     └──────────────────┘
     5분 소요                  2분 소요                 설정 완료! 🎉
```

---

### 1단계: 카카오 로그인

1. 담당자에게 받은 **서비스 URL**을 카카오톡에서 엽니다
2. **[카카오 로그인]** 버튼을 탭합니다

```
┌─────────────────────────┐
│                         │
│     기억의 정원 🌿      │
│                         │
│  ┌─────────────────┐    │
│  │  카카오로 시작  │    │
│  └─────────────────┘    │
│                         │
└─────────────────────────┘
         ↓ 탭
┌─────────────────────────┐
│   카카오계정으로 로그인  │
│                         │
│  [필수] 닉네임/프로필   │
│  [필수] 카카오톡 메시지 │  ← 반드시 동의
│                         │
│      [동의하고 계속]    │
└─────────────────────────┘
```

> 💡 **동의 항목 안내**
> - ✅ **닉네임 및 프로필 사진** (필수): 대화에 이름을 사용합니다
> - ✅ **카카오톡 메시지 전송** (필수): 나에게 보내기 알림에 사용합니다
> - ⬜ 친구 목록 (선택): 동의하지 않아도 무관합니다

3. 로그인 완료 후 **채널 연동 링크**가 나타납니다

---

### 2단계: 채널 추가 및 연동

1. 로그인 후 화면에 표시되는 **"채널 연동하기"** 버튼을 탭합니다

```
┌─────────────────────────┐
│   로그인 완료! 🎉       │
│                         │
│  이제 채널을 연동하면   │
│  AI와 대화할 수 있어요  │
│                         │
│  ┌─────────────────┐    │
│  │  채널 연동하기  │    │
│  └─────────────────┘    │
│                         │
│   (5분 내에 채널에서    │
│    메시지를 보내주세요) │
└─────────────────────────┘
         ↓ 탭
```

2. **@기억의 정원** 채널로 이동합니다
3. **[채널 추가]** 버튼을 탭합니다 (아직 추가하지 않은 경우)
4. 채널 채팅방에서 **아무 메시지나** 입력합니다 (예: "안녕하세요")

```
카카오톡 채널 채팅방
┌─────────────────────────┐
│  @기억의정원 🌿         │
│─────────────────────────│
│                         │
│                         │
│  ← 여기에 메시지 입력  │
│                         │
│ [안녕하세요]  [전송]    │
└─────────────────────────┘
         ↓ 메시지 전송
┌─────────────────────────┐
│  @기억의정원 🌿         │
│─────────────────────────│
│  나: 안녕하세요         │
│                         │
│  기억의정원:            │
│  반갑습니다! 연동이 완  │
│  료되었습니다 🌱        │
│  잠시 후 첫 대화가     │
│  시작됩니다!            │
└─────────────────────────┘
```

> ⚠️ **주의**: 채널 연동 링크를 받은 후 **5분 내**에 채널에서 메시지를 보내야 합니다.
> 5분이 지나면 다시 로그인 URL을 통해 연동 링크를 받아야 합니다.

---

### 설정 완료!

두 단계가 완료되면 서비스가 시작됩니다.

```
설정 완료 후 진행 흐름:

카카오 로그인 완료
       +
채널 연동 완료
       ↓
  하루 3번 알림
  (나에게 보내기)
       ↓
  채널방에서 대화
       ↓
  AI 인지 분석 (백그라운드)
       ↓
  필요 시 보호자 알림
```

## 3. 일상적인 사용법

### 대화 흐름

매일 정해진 시간에 AI가 먼저 말을 겁니다.

**Step 1: 알림 수신**

정해진 시간이 되면 **"나에게 보내기"** 로 알림이 옵니다.

```
카카오톡 알림
┌─────────────────────────────┐
│  📱 카카오톡                │
│                             │
│  나에게 보내기              │
│  ┌───────────────────────┐  │
│  │  기억의정원에서 안부를 │  │
│  │  전합니다 🌿           │  │
│  │                       │  │
│  │  오늘 아침은 어떠세요? │  │
│  │                       │  │
│  │  [채널에서 답하기 🌱] │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

> 💡 **나에게 보내기란?**
> 카카오톡에서 자기 자신에게 보내는 메시지입니다.
> **채널방이 아닌 "나"와의 대화방**에 옵니다.

**Step 2: 채널에서 대화**

1. 알림 메시지의 **[채널에서 답하기 🌱]** 버튼을 탭합니다
2. **@기억의 정원** 채널 채팅방으로 이동합니다
3. 자유롭게 대화합니다

```
나에게 보내기 메시지              채널 채팅방
┌───────────────────┐           ┌───────────────────┐
│  나에게 보내기    │           │  @기억의정원 🌿   │
│───────────────────│           │───────────────────│
│  오늘 아침은      │    탭     │  기억의정원:      │
│  어떠세요? 🌿    │ ────────▶ │  오늘 아침은      │
│                   │   버튼    │  어떠세요? 🌿    │
│  [채널에서        │           │                   │
│   답하기 🌱]     │           │  나:              │
└───────────────────┘           │  잘 잤어요! 오늘 │
                                │  날씨가 좋네요   │
                                │                   │
                                │  기억의정원:      │
                                │  다행이에요 😊   │
                                └───────────────────┘
```

**Step 3: 대화 분석 (자동)**

대화 내용은 자동으로 AI가 분석합니다.
사용자는 별도로 할 일이 없습니다.

```
채널 대화 완료
     ↓
  (백그라운드 자동 처리)
  ┌─────────────────────┐
  │  어휘 풍부도 분석   │
  │  의미적 일관성 분석 │
  │  기억력 평가        │
  │  시간 지남력 평가   │
  └─────────────────────┘
     ↓
  종합 점수 (MCDI) 계산
     ↓
  이상 징후 없음 → 정상
  이상 징후 발견 → 보호자 알림
```

## 4. 사진 공유하기

채널 대화 중 **사진을 공유**하면 AI가 사진 속 내용을 분석합니다.

### 사진 공유 흐름

```
채널 채팅방에서 사진 전송
         ↓
┌─────────────────────────┐
│  기억의정원:            │
│  사진을 받았어요! 🌿   │
│  잠깐만 기다려 주세요, │
│  사진을 살펴볼게요...  │
└─────────────────────────┘
         ↓ (분석 중, 약 10~30초)
┌─────────────────────────┐
│  나에게 보내기          │  ← 분석 결과는
│  ┌───────────────────┐  │    나에게 보내기로 옵니다
│  │  사진을 봤어요 📸 │  │
│  │                   │  │
│  │  꽃이 가득한      │  │
│  │  정원 사진이네요  │  │
│  │  봄 산책을 즐기셨 │  │
│  │  나요? 🌸        │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

> 💡 **왜 나에게 보내기로 올까요?**
> 카카오 채널의 기술적 특성상, AI가 분석을 마친 후 채널방에 직접 메시지를 넣을 수 없습니다.
> 현재 베타 기간에는 분석 결과를 **나에게 보내기**로 보내드립니다.
> 정식 서비스 시에는 채널방에서 바로 받아보실 수 있도록 개선할 예정입니다.

### 어떤 사진을 보내면 좋을까요?

```
좋은 사진 예시:
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   🌸         │  │   👨‍👩‍👧         │  │   🏡         │
│              │  │              │  │              │
│  꽃, 식물    │  │  가족 사진   │  │  집, 동네    │
│  정원 풍경   │  │  추억 사진   │  │  여행 사진   │
└──────────────┘  └──────────────┘  └──────────────┘
```

## 5. 이미 채널을 사용 중이신 분

> 이전에 채널을 통해 이미 대화를 나눈 적이 있으신 분은 이 섹션을 참고하세요.

### 계정을 삭제할 필요가 없습니다!

기존 채널 전용 계정을 삭제하지 않아도 됩니다.
**카카오 로그인(OAuth)** 을 진행하면 자동으로 기존 대화 기록과 통합됩니다.

### 통합 흐름

```
기존 상태:
┌──────────────────────────────┐
│  채널 전용 계정              │
│  - 채널 대화 기록 있음       │
│  - 나에게 보내기 불가        │
│  - 스케줄 알림 없음          │
└──────────────────────────────┘
           ↓ OAuth 로그인 + 채널 연동
┌──────────────────────────────┐
│  통합 계정 ✅                │
│  - 기존 대화 기록 유지       │
│  - 나에게 보내기 가능        │
│  - 스케줄 알림 시작          │
└──────────────────────────────┘
```

### 통합 방법

[2단계 시작하기](#2-시작하기-최초-설정)와 동일하게 진행하면 됩니다.

1. 담당자에게 받은 서비스 URL 접속
2. 카카오 로그인
3. 채널 연동하기 버튼 탭
4. 채널에서 메시지 전송

## 6. 자주 묻는 질문 (FAQ)

### Q1. 채널 알림은 언제 오나요?

**A.** 매일 세 번 옵니다: **오전 9시**, **오후 2시**, **저녁 7시**

알림은 **나에게 보내기** 메시지로 옵니다.
메시지 속 **[채널에서 답하기 🌱]** 버튼을 눌러 채널방에서 대화하세요.

---

### Q2. 채널 알림이 오지 않아요.

**A.** 다음 사항을 확인하세요:

```
확인 순서:
1. 카카오 로그인(OAuth)을 완료했나요? ✅
2. 채널 연동을 완료했나요? ✅
3. 카카오톡 알림이 켜져 있나요? ✅
4. "나에게 보내기" 메시지를 확인했나요? ✅
   (채널방이 아닌 "나"와의 채팅에서 확인)

그래도 오지 않으면 → 담당자에게 연락
```

---

### Q3. 채널 연동 링크가 만료됐어요.

**A.** 채널 연동 링크는 **5분**간 유효합니다.
서비스 URL에 다시 접속해서 카카오 로그인을 한 후 새 연동 링크를 받으세요.

---

### Q4. "나에게 보내기"와 채널방이 다른 곳인가요?

**A.** 네, 서로 다른 공간입니다.

```
카카오톡 채팅 목록
┌─────────────────────────────┐
│  💬 채팅                    │
│─────────────────────────────│
│  나 (나에게 보내기)  ← 알림  │
│    └ 기억의 정원 알림 수신   │
│                             │
│  @기억의정원 🌿     ← 대화  │
│    └ 여기서 대화 진행       │
└─────────────────────────────┘
```

- **나에게 보내기**: AI의 알림 및 사진 분석 결과 수신
- **@기억의 정원 채널**: 실제 대화가 이루어지는 곳

---

### Q5. 대화하지 않은 날은 어떻게 되나요?

**A.** 대화하지 않아도 괜찮습니다.
답장하지 않은 날은 분석에서 제외됩니다.
다음 알림 때 다시 대화할 수 있습니다.

---

### Q6. 보호자에게는 어떤 알림이 가나요?

**A.** 베타 테스트 기간에는 **보호자 알림 기능이 아직 구현되지 않았습니다.**
대화 분석 결과는 내부 DB에 누적 저장되며, 담당자가 주기적으로 확인합니다.
보호자 등록 및 자동 알림 기능은 정식 서비스 시 제공될 예정입니다.

---

### Q7. 개인 정보는 안전한가요?

**A.** 네. 다음과 같이 보호됩니다:

- 대화 내용은 암호화하여 저장됩니다
- 담당자 외에는 개인 대화 내용을 볼 수 없습니다
- 분석에는 익명화된 데이터가 사용됩니다
